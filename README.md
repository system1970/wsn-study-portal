## 🎯 Curriculum Covered

- **Unit-III (174 Slides)**: Data Link Layer, MAC Responsibilities, Contention-Free Protocols (TRAMA, Y-MAC, DESYNC-TDMA, LEACH, LMAC, MLMAC), Contention-Based Protocols (PAMAS, S-MAC, T-MAC, PMAC, RMAC, DW-MAC, DMAC, WiseMAC, RI-MAC), Hybrid MAC (Z-MAC, MH-MAC).
- **Unit-IV (192 Slides)**: Network Layer, Routing Metrics (ETT, ETX, Energy, Partition), Flooding & Gossiping (Implosion, Overlap, Resource Blindness), Data-Centric Routing (SPIN-PP/EC/BC/RL, Directed Diffusion, Rumor Routing, GBR), Proactive Routing (DSDV, OLSR with MPRs), Reactive Routing (AODV, DSR), Hierarchical Routing (Landmark, LANMAR, LEACH, PEGASIS, Safari), Location-Based Routing (GPSR, Right-Hand Rule, GAF, SPBM, GEAR, GFPG), QoS-Based Routing (SAR, SPEED, MMSPEED), Data Aggregation (TAG, DRINA, HEED, CLUDDA).
